# INSTALLATION ON WINDOWS 11:
# ---------------------------
# 1. Install Python 3.10+ from https://www.python.org/downloads/
# 2. Install Visual Studio Build Tools (for some packages):
#    https://visualstudio.microsoft.com/visual-cpp-build-tools/
# 3. Install FFmpeg: 
#    - Download from https://www.gyan.dev/ffmpeg/builds/
#    - Add to PATH: setx PATH "%PATH%;C:\ffmpeg\bin"
# 4. Create virtual environment:
#    python -m venv venv
#    venv\Scripts\activate
# 5. Install dependencies:
#    pip install -r requirements.txt
#
# NOTE: Some packages may require additional setup on Windows:
# - dlib: Requires CMake and Visual Studio Build Tools
# - face-recognition: Depends on dlib (optional, see below)
# - weasyprint: Requires GTK (see https://doc.courtbouillon.org/weasyprint/stable/first_steps.html#windows)
#
